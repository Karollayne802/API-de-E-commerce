# API de E-commerce

API backend de uma plataforma de e-commerce (estilo Amazon) desenvolvida em **Node.js + Express**. Ela gerencia usuários, produtos, carrinho de compras, pedidos e avaliações, usando dados em memória (mockados) para simular um banco de dados.

## Tecnologias

- [Node.js](https://nodejs.org/) (v20+)
- [Express](https://expressjs.com/)
- [express-session](https://www.npmjs.com/package/express-session)
- [cookie-parser](https://www.npmjs.com/package/cookie-parser)
- [express-validator](https://express-validator.github.io/)
- [bcryptjs](https://www.npmjs.com/package/bcryptjs)

## Como rodar

```bash
# 1. Instale as dependências
npm install
```
```
# 2. Suba o servidor
npm start
```

O servidor roda em `http://localhost:3000`.
